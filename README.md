# corvo-api
Restful Api Wrapper for Corvo Categorization Engine letting frontend access and send data over HTTP without having to run and download any of the bigger ML Models locally.

API Functionality:
Full Process (Norm + Cat),
Normalization,
Categorization,
Get Taxonomy Schema,
Rules only Cat + Norm,
ML Cat + Norm,
LLM Cat + Norm,
Cat by Flag
